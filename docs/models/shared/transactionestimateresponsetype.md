# TransactionEstimateResponseType

Type of the address. Must be either
                        SHIP_TO or BILL_TO.

## Example Usage

```ruby
require "kintsugi_sdk"

value = TransactionEstimateResponseType::SHIP_TO
```


## Values

| Name      | Value     |
| --------- | --------- |
| `SHIP_TO` | SHIP_TO   |
| `BILL_TO` | BILL_TO   |
